# Personal Finance Bot — Public Showcase

Премиальная публичная презентация персонального Telegram-бота и Mini App для управления финансовыми балансами и дневным бюджетом.

**Сайт после активации GitHub Pages:** https://sergekoroleff.github.io/personal_finance_bot_showcase/

> **Важно:** этот репозиторий содержит только статический showcase. Здесь нет банковских данных, токенов, Google Sheets ID, ключей, адресов VPS, приватных API и кода основного финансового приложения. Все суммы внутри демонстрационного макета вымышлены.

## Содержание

- Функции принятой версии **v0.10 Smart Financial Assistant**: дневной лимит на сегодня/завтра, закрытие дня, быстрые What-if сценарии, кредитные лимиты, карты в разных валютах (read-only), Financial Calendar, Goal Simulator, History 2.0 и Highlights.
- Интерактивный демонстрационный интерфейс (обзор, балансы, другие карты, история) — **не настоящий скриншот и не подключение к реальным данным**.
- Архитектура: Telegram → HTTPS Mini App / Telegram Bot → приватный сервер приложений → Google Sheets (балансы) + SQLite (история закрытий).
- Безопасность: авторизация через Telegram initData, личный allowlist, изолированные сервисы, Google API permissions, явное подтверждение ежедневного закрытия.
- Галерея-заготовка для реальных скриншотов.

## GitHub Pages: включить однократно

1. Открой **Settings → Pages** именно в публичном репозитории.
2. В **Build and deployment** выбери **Deploy from a branch**.
3. Укажи **main** и **/(root)**, нажми **Save**.
4. Дождись публикации и открой [showcase](https://sergekoroleff.github.io/personal_finance_bot_showcase/).

Если GitHub Pages уже активирован на main/root, дополнительных действий не нужно.

## Реальные скриншоты (позже)

Скриншоты в текущей версии **не используются**; галерея показывает явно обозначенные плейсхолдеры. Когда будут материалы:

1. Сними экраны Telegram Mini App (обзор, балансы, другие карты, история), скрыв или заменив суммы и личные сведения.
2. Добавь их в папку \`assets/screenshots/\`.
3. Замени плейсхолдеры галереи на \`<img>\` через отдельный коммит; сохрани fallback и адаптивность.

**Не публиковать** реальные суммы, реквизиты, идентификаторы таблиц, токены и детали доступа к VPS.

## Ограничения и принципы

- Только чистые HTML / CSS / JS: без сборщика, веб-аналитики, CDN-библиотек и внешних запросов к банковским API.
- Никаких кнопок, претендующих на реальное закрытие дня или изменение балансов.
- Версия продукта на витрине: **v0.10 Smart Financial Assistant (принята владельцем, 21.10.2026)**. Старые разделы ниже и выше сохранены как история.
- v0.9 Smart Daily Close: активны вечернее напоминание и ночной таймер; последний известный ночной результат `ALREADY_CLOSED` (защита от повторной записи). Утренняя рассылка v0.10 подготовлена, но не активирована.

## v0.9 Daily Intelligence — 20 октября 2026

- Smart Daily Close: напоминание в 21:30 МСК и автозакрытие в 23:59 по последнему черновику, явно сохранённому в течение московского дня. Без черновика — пропуск и попытка уведомления. Первое реальное ночное выполнение ещё ожидает проверки.
- Spending Analytics: оценка чистой динамики доступных остатков карт по последовательным закрытым дням, сравнение недели и месяца. Это не точные покупки или банковская транзакционная история.
- Financial Health Score: внутренний показатель 0–100 (кредитная нагрузка 40%, доступный дневной бюджет 35%, динамика долга 25%). Не банковский кредитный рейтинг; при недостатке истории показатель не рассчитывается.

Весь контент публичной витрины демонстрационный; финансовые данные и служебные настройки отсутствуют. Версия основного приложения: v0.9.

## v0.10 Smart Financial Assistant — 21 октября 2026

**Принят владельцем в Telegram Mini App:** пять пунктов чеклиста подтверждены. Основное приложение развернуто на VPS: 4 основных и 2 новых smoke-теста пройдены, API и существующие таймеры активны. Вчерашний результат ночного запуска `ALREADY_CLOSED` подтверждает идемпотентность, но ещё не реальное автозакрытие открытого дня.

Новые возможности:
- **Daily Control Center** — статус дня, сохранённый черновик, синхронизация и расписание.
- **Morning Finance Briefing** — подготовлен read-only сценарий утреннего обзора в Telegram на 08:30 МСК; **автоматическая отправка пока выключена**.
- **Spending Analytics 2.0** — оценка чистого изменения остатков двух карт, контекст предыдущей недели, детализация дня и явное покрытие периода.
- **Health Score Insights** — объяснение факторов и несохраняемый сценарий уменьшения долга.
- **Smart Financial Goals** — сохраняемая финансовая цель и процент её достижения без изменения Google Sheets.

**Отдельная витрина релиза:** [v0.10 · Smart Financial Assistant](https://sergekoroleff.github.io/personal_finance_bot_showcase/v010.html). Иллюстрации, цифры и графики являются синтетическими. Личная финансовая информация и приватные параметры здесь отсутствуют.
