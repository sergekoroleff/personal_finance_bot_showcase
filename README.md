# Personal Finance Bot — Public Showcase

Премиальная публичная презентация персонального Telegram-бота и Mini App для управления финансовыми балансами и дневным бюджетом.

**Сайт после активации GitHub Pages:** https://sergekoroleff.github.io/personal_finance_bot_showcase/

> **Важно:** этот репозиторий содержит только статический showcase. Здесь нет банковских данных, токенов, Google Sheets ID, ключей, адресов VPS, приватных API и кода основного финансового приложения. Все суммы внутри демонстрационного макета вымышлены.

## Содержание

- Функции принятой версии **v0.14 Financial Accuracy & Insights**: дневной лимит на сегодня/завтра, закрытие дня, быстрые What-if сценарии, кредитные лимиты, карты в разных валютах (read-only), Financial Calendar, Goal Simulator, History 2.0 и Highlights.
- Интерактивный демонстрационный интерфейс (обзор, балансы, другие карты, история) — **не настоящий скриншот и не подключение к реальным данным**.
- Архитектура: Telegram → HTTPS Mini App / Telegram Bot → приватный сервер приложений → Google Sheets (балансы) + SQLite (история закрытий).
- Безопасность: авторизация через Telegram initData, личный allowlist, изолированные сервисы, Google API permissions, явное подтверждение ежедневного закрытия.
- Галерея-заготовка для реальных скриншотов.

## GitHub Pages: включить однократно

1. Открой **Settings → Pages** именно в публичном репозитории.
2. В **Build and deployment** выбери **Deploy from a branch**.
3. Укажи **main** и **/(root)**, нажми **Save**.
4. Дождись публикации и открой [showcase](https://sergekoroleff.github.io/personal_finance_bot_showcase/).

Если GitHub Pages уже активирован на main/root, дополнительных действий не нужно.

## v0.9 Daily Intelligence — 20 октября 2026

- Smart Daily Close: напоминание в 21:30 МСК и автозакрытие в 23:59 по последнему черновику, явно сохранённому в течение московского дня. Без черновика — пропуск и попытка уведомления. Первое реальное ночное выполнение ещё ожидает проверки.

- Financial Health Score: внутренний показатель 0–100 (кредитная нагрузка 40%, доступный дневной бюджет 35%, динамика долга 25%). Не банковский кредитный рейтинг; при недостатке истории показатель не рассчитывается.

Весь контент публичной витрины демонстрационный; финансовые данные и служебные настройки отсутствуют. Версия основного приложения: v0.9.

**Принят владельцем (Telegram Mini App, 5/5 проверок)**. Перед выпуском успешно выполнены 4 финансовых core smoke-теста и 3 целевые проверки v0.11 (7/7). Публичная витрина представляет только синтетические данные.

- **Reliability Center** — отображение зарегистрированных результатов утренних отправок, автозакрытий, последнего закрытия и синхронизации.

## v0.13 · Smart Finance Experience — 21 октября 2026

**Статус:** выпущено на VPS (владелец подтвердил Git SHA `f079c6f` и активное состояние API), все пять интерфейсных улучшений отображаются в Telegram Mini App. Изолированные Python-тесты пройдены **20/20**; дополнительная синтетическая проверка погашений и автозакрытия вернула `RESULT=PASS`. Это не подтверждает ещё реальный день с ненулевым погашением — такая проверка остаётся открытой.

**Пять обновлений:** Card Repayments & Spending Analytics 3.0 (добавлены явные суммы погашений по Т-Банку и ОТП и расчётная оценка расходов); Dashboard 2.0 (основные показатели); Planned Expenses 2.0 (статусы и фильтры); Budget Guard (пороговые предупреждения); Explain My Numbers (описание используемых формул).

Расчётная оценка движения средств по карте при стабильном лимите: предыдущий доступный остаток − новый доступный остаток + погашения, зачисленные в течение дня. Это **не банковские транзакции**: возвраты, кэшбэк и комиссии могут влиять на результат. Исторические записи без сведений о погашениях помечаются как неизвестные. Нельзя повторно прибавлять погашения к `Бюджет light`.

**Страница релиза:** [v0.13 · Smart Finance Experience](https://sergekoroleff.github.io/personal_finance_bot_showcase/v013.html). Всё статическое, иллюстрации и суммы вымышленные; ни реальной авторизации, ни подключения к закрытой системе нет.

**Операционные проверки в ожидании:** подтверждение реального погашения в черновике/закрытии и аналитики двух последовательных закрытых дней; первая фактическая доставка Morning Briefing 22 октября 2026 года в 09:00 МСК; первое успешное автозакрытие действительно открытого дня.
